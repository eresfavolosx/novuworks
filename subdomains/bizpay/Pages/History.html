Fintech Architecture Overview

BizPay Commercial Platform & ATH Móvil Integration

BizPay was architected by Fabián Vélez Vicente to streamline commercial invoicing, payment routing, and real-time merchant fee calculations for B2B enterprises in Puerto Rico. The platform integrates directly with the ATH Móvil Business API to enable instantaneous, zero-slippage checkouts without paper invoicing delays.

Frequently Asked Questions

Technical Implementation Details

How does the ATH Móvil modal handoff work?

When a user initiates checkout, BizPay bundles the order payload with merchant credentials and launches the ATH Móvil transaction iframe or mobile deep-link, ensuring full PCI-DSS tokenization without exposing sensitive card credentials to merchant servers.

How does ledger reconciliation operate?

Completed payments emit an asynchronous webhook notification containing the transaction token, settling the invoice status from "Unpaid" to "Paid" in real time while recalculating the commercial cash-flow chart.

Where can I review the source code?

The open-source code and architectural documentation are available on GitHub (eresfavolosx/BizPay).
