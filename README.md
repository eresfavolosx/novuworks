## 🌟 Why This Exists

Technology is at its best when it invites people to participate, reflect, and imagine. **Novu Works** is an open-source creative technology playground and living laboratory where **Frontier Models**, **Human-Centric Design**, **Interactive Experiences**, **Generative Prototypes**, **Orchestration**, **Tool-Calling**, and **Synthesis** converge in the browser.

Every experiment in this repository was born from an open-ended human question—whether helping 300M+ people with color-vision deficiency hear and feel the emotional warmth of color in real time, turning physical NFC hardware tokens into tactile portals of connection, or replacing job-search burnout with an empathetic autonomous agent.

## 🧪 The Three-Part Creative Technology Lens

### 1. The Concept
What if a portfolio wasn't a static document of past work, but a responsive, playful canvas that invites visitors to touch, test, and co-create with frontier systems right in their browser? Every prototype on `novu.works` is guided by **humor, emotional depth, optimism, and meaningful impact**.

### 2. The Technology
Engineered from scratch with zero bloated frameworks—combining **Three.js WebGL2 custom GLSL shaders**, **procedural 60 FPS particle physics**, **Web Audio API polyphonic synthesis**, **WebRTC real-time camera vision**, **Web NFC physical hardware serialization**, **multi-perspective LLM synthesis**, and **WCAG AAA accessible design**.

### 3. The Impact
Delivers an instant, joyful creative playground that runs at 60 FPS across mobile devices, desktops, and even in-vehicle touchscreens—uniting 7 interactive sub-experiences and open-source experiments under one cohesive narrative.

## 🔬 Featured Interactive Experiments & Substantiated Resume Prototypes

### 1. **Procedural Physics Portfolio & NFC Physical-Digital Objects** (`novu.works` & `nfc.novu.works`)
> **Substantiated Resume Claim:** *"Coded interactive procedural physics web experiences and prototyped a cross-platform mobile and physical NFC tap experience (Capacitor, Firebase, Vite) assisted by an autonomous coding agent to connect physical objects with digital play."*
- **The Concept:** Digital connection shouldn't be trapped behind flat screens and static QR codes. We coded interactive 60 FPS procedural physics web experiences right on [`novu.works`](https://novu.works) and prototyped **Tocaito** (`nfc.novu.works`)—a cross-platform mobile and physical NFC tap experience designed to connect physical objects (wristbands, rings, badges, and studio tokens) with tactile digital play.
- **The Technology:**
  - **Procedural Physics Web Experiences (`novu.works`):** Custom **Three.js WebGL2 GLSL shaders**, **60 FPS spring-damped procedural particle physics** (`src/minimal-particle-matrix.js`, `src/sculpture.js`), **6DoF gyroscope spatial tilt**, and kinetic shockwave fields.
  - **Cross-Platform Mobile & Physical NFC Tap (`Capacitor, Firebase, Vite`):** Built from a unified **Vite** codebase packaged for native mobile via **Capacitor 8** (`capacitor.config.json`, `ios/`) and the web via the **Chrome Web NFC API (`NDEFReader`)** backed by **Firebase Cloud Firestore & Hosting** (`firebase.json`).
  - **Autonomous Coding Agent Collaboration (`.Jules/` & `verification.py`):** Iteratively prototyped and verified alongside autonomous coding agents (`.Jules/bolt.md`, `.Jules/palette.md`, `.Jules/sentinel.md`) and a headless Python Playwright QA suite.
- **The Impact:** Connects physical artifacts with responsive digital play in under **0.4 seconds**—allowing creators, event hosts, and players to reprogram physical NFC tokens over the air in real time without reflashing silicon.
- **Repositories:** [`eresfavolosx/novuworks`](https://github.com/eresfavolosx/novuworks) · [`eresfavolosx/NFC`](https://github.com/eresfavolosx/NFC)

### 2. **JobHelper & FavoBot** — *Original Python & LLM Agent Companions* (`jobhelper.novu.works`)
> **Substantiated Resume Claim:** *"JobHelper & FavoBot (https://github.com/eresfavolosx/JobHelper): Designed and engineered original Python and LLM agent companions exploring autonomous reasoning, 100-point rubric critique, and everyday human-AI collaboration."*
- **The Concept:** Job hunting and daily technical orchestration often feel like shouting into an algorithmic void or babysitting a terminal. **JobHelper** and its sister pocket companion **FavoBot** reimagine career discovery and daily mission execution as an optimistic, candid collaboration between humans and frontier AI companions.
- **The Technology:**
  - **100-Point Rubric Critique (`src/lib/job-service.js` & `scripts/rubric_agent_companion.py`):** Uses **Gemini 2.0 Flash / OpenAI** structured JSON reasoning to critique and score role alignment on a deterministic `0–100` rubric across four weighted dimensions, returning transparent reasoning traces.
  - **Original Python & LLM Autonomous Reasoning (`scripts/rubric_agent_companion.py`, `supra_engine.py`, `employer_brain.py`, `reward_engine.py`):** Multi-step Python agent brains paired with **Next.js 16**, **Docker**, a **Manifest V3 Chrome Extension**, and **Telegram/Discord** bridges for everyday human-AI collaboration.
- **The Impact:** Gives makers back their time and creative confidence—delivering transparent 100-point rubric critiques in under 2 seconds and conversational mission execution from anywhere.
- **Repositories:** [`eresfavolosx/JobHelper`](https://github.com/eresfavolosx/JobHelper) · [`eresfavolosx/FavoBot`](https://github.com/eresfavolosx/FavoBot)

### 4. **BizPay** — *Playful Peer-to-Peer Community Micro-Economy* (`bizpay.novu.works`)
- **The Concept:** Splitting a dinner bill, tipping a local street musician, or pooling funds for a neighborhood project shouldn't feel like filing taxes. BizPay reimagines local value exchange as an effortless, transparent, and celebratory social interaction.
- **The Technology:** Engineered with **Angular**, **Ionic Capacitor**, **TypeScript**, and **Firebase Cloud Firestore** real-time listeners. Orchestrates peer-to-peer ledger state, dynamic **QR payload encoding**, and tactile micro-interactions with offline-first resilience.
- **The Impact:** Brings warmth and instant clarity to everyday community exchanges, making mutual support and shared expenses feel natural and friction-free.
- **Repository:** [`eresfavolosx/BizPay`](https://github.com/eresfavolosx/BizPay)

### 5. **Hackea Por Una Causa** — *Civic Co-Creation & Disaster-Resilient Story Hub* (`hackea.novu.works`)
- **The Concept:** Born in Puerto Rico after hurricanes disrupted island-wide infrastructure, this platform asks: *how can we gather engineers, artists, and neighbors into a shared digital commons to build life-saving civic prototypes together?*
- **The Technology:** Built with **HTML5**, **CSS3**, **JavaScript**, and resilient **Firebase Edge Hosting**—optimized for ultra-low bandwidth, instant mobile loading over satellite/cellular links, and accessible bilingual navigation.
- **The Impact:** Mobilized hundreds of student makers, mentors, and community leaders to co-create open-source tools for emergency relief, education, and local resilience.
- **Repository:** [`eresfavolosx/hackeaporunacausa`](https://github.com/eresfavolosx/hackeaporunacausa)

### 6. **Liza's Sobriety Counter** — *Compassionate Milestone & Reflection Companion* (`liza.novu.works`)
- **The Concept:** Recovery is a deeply personal journey built one second, one hour, and one courageous day at a time. Created as a heartfelt gift of encouragement, this interactive experience turns time itself into a gentle, luminous celebration of human resilience.
- **The Technology:** Crafted with **Vanilla JavaScript**, a precision **1000ms temporal delta engine**, **HTML5 Canvas celebratory particle physics**, and warm **CSS glassmorphic lighting** that adapts to every milestone unlocked.
- **The Impact:** Offers a quiet, uplifting pocket sanctuary where every single heartbeat of progress is seen, honored, and celebrated with emotional depth and optimism.

### 7. **TokenFund** — *Programmable Community Grants & Transparent Patronage*
- **The Concept:** Supporting grassroots creators and public-good experiments often gets bogged down in opaque gatekeeping. TokenFund explores how transparent, programmable rules can help communities co-fund the ideas they care about most.
- **The Technology:** Written in **Solidity** using deterministic state machines, automated milestone verification, and verifiable on-chain event logs with zero middleman custody.
- **The Impact:** Gives independent makers and neighborhood collectives a trustworthy, open-source canvas for collaborative patronage.
- **Repository:** [`eresfavolosx/TokenFund`](https://github.com/eresfavolosx/TokenFund)

## 🛠️ Local Development & Exploration

```bash
# 1. Clone the creative technology atelier
git clone https://github.com/eresfavolosx/novuworks.git
cd novuworks

# 2. Install dependencies
npm install

# 3. Launch the interactive Vite dev server (http://localhost:5173)
npm run dev

# 4. Build production bundle & sync all interactive sub-experiences
npm run build
```
