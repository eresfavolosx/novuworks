* Features 3 interactive topological morph states:
  * `01 · Novu Works Monogram`
  * `02 · Möbius Growth Ribbon`
  * `03 · Quantum AI Prism`
* Defensive context-loss recovery and dynamic camera choreography across viewport view states.

## 🛠️ Tech Stack & Tooling

* **Frontend:** Vanilla TypeScript / Modern ES2024 Modules, HTML5, Modular CSS3 Custom Properties.
* **Graphics & Animation:** Three.js (r128), WebGL Shader Materials, CSS 3D transforms.
* **Audio Synthesis:** Web Audio API oscillator chains with tactile acoustic micro-interactions.
* **Build System:** Vite v8 with Rolldown compiler and LightningCSS minifier.
* **Hosting & CDN:** Google Firebase Hosting with global edge caching and HTTP/2.
* **Data Sources:** Databricks SQL, PySpark, Google Tag Manager Server-Side, Conversions API (CAPI), GA4 Measurement Protocol, Hacker News Algolia Search API.

## 🚀 Local Development

```bash
# 1. Clone repository
git clone https://github.com/eresfavolosx/novuworks.git
cd novuworks

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build

# 5. Preview production build locally
npm run preview
```
